# Adeel Mobile Installments

Independent project scaffold.

## Locked development scope
1. Shared Admin/User login page
2. Admin dashboard
3. Admin sidebar navigation
4. Users module
5. Create User page
6. All Users page
7. Testing and fixes for the above scope

The public customer website and all later modules are intentionally deferred.

## Important rules
- Keep all project work inside this folder.
- Do not modify the existing AdeelMobile project files outside this folder.
- Do not change Supabase until separately authorized.
- Build and test one file/module at a time.
- These folders are scaffolding only; application code will be added in approved steps.
